# elvismao.com

The personal website of Elvis Dragon Mao (毛哥EM), with an interactive homepage, a portfolio, a newsletter, and a collection of web tools. Available in English, Traditional Chinese, and Simplified Chinese.

[elvismao.com](https://elvismao.com/)

## Run locally

```sh
pnpm install
pnpm dev
```

Open [localhost:4326](http://127.0.0.1:4326/). To preview the 3D homepage on a fresh checkout, run `pnpm build` first to restore the character model.
